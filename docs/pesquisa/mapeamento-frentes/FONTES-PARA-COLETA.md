# Fontes dos três kits — lista integral de consulta

Esta lista preserva as 93 entradas dos inventários, inclusive repetições e fontes já aproveitadas. Não significa 93 aquisições necessárias. Títulos portugueses do kit militar são descrições de trabalho. Formatos provêm dos inventários, exceto classificações explícitas de PDFs/livros; não houve verificação de acesso de todas as URLs.

## Como decidir o que pegar

- Fonte URL correspondente: reutilizar o documento cadastrado.
- Seção candidata: já há conteúdo relacionado na compilação; obter outra edição apenas para complementar ou cotejar.
- Sem correspondência: procurar/obter a fonte; referência não é garantia de transcrição disponível.
- Mesmo endereço pode conter vários documentos (livro/compilação). Baixar uma vez e identificar os trechos separadamente.

## Os três registros de Ezhov sem seção própria

- EZH-014, 07/07/1939: extrato textual HTML em https://istmat.org/node/64182, consultado em 17/10/2026; não é a íntegra do interrogatório.
- EZH-016, 17/07/1939: mencionado na acareação de 21/07 na compilação Furr; sem link fornecido para um protocolo próprio.
- EZH-024, 31/01/1940: referência bibliográfica a Pavliukov, p. 529; sem link fornecido para transcrição própria.
