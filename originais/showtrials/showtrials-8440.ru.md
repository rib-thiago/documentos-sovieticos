разговоров по объекту “В-87”

13 -14 марта 1938 г.

( Бухарин – Зарицкий )

22.00 ( Играют в шахматы )

23.05

II мужчина: Вы спрашивали, что вас переведут?

I мужчина: Кто смертников переводит? Я уже смертник, у меня уже жизни нет. ( пауза ) Ох, тяжко\!

( играют в шахматы )

23.20

Ой, дышать нечем. ( открывает форточку )

( пауза )

II мужчина: Ничего не понимаю. ( пауза )

I мужчина: Ой, только бы скорее смерть приходила.

II мужчина: Что с вами?

I мужчина: Я уже на смертном одре, вы не понимаете? Я так расстроен, что вы себе не представляете. Я теперь все время спать не буду. ( пауза )

II мужчина: А как теперь другие?

I мужчина: Всех, наверное, перевели в другие – смертные камеры, маленькие. Вам-то легко.

II мужчина: Мне-то легко, а вам-то каково\!

I мужчина: Я не особенно хороший предзнаменователь.

II мужчина: Да бросьте вы. ( играют в шахматы )

I мужчина: У меня голова болит со вчерашнего дня еще.

( играют в шахматы )

1.50

I мужчина: Тяжело все-таки умирать, а кажется так легко. Боже мой, боже\!

14/ III -38 г.

9.30

I мужчина: Дальше что же?

II мужчина: Ничего.

9.46 ( Вошел вахтер )

II мужчина: Спасибо. Чаю вот бы. ( вахтер вышел )

9.55

II мужчина: Какое у вас плохое настроение.

I мужчина: Я не выспался.

II мужчина: Вы позже меня заснули. ( пауза )

I мужчина: Что же это такое? Скорей бы\!

( молчание )
