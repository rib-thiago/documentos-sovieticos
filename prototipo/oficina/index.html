Uma bancada, vários instrumentos

Escolha um documento no acervo. Abra Markdown e Prévia; arraste as abas para as bordas para colocá-las lado a lado. Cada painel pode ser fechado e reaberto.

  1. Leitura: clique em um parágrafo para marcar; clique novamente para desmarcar. Use Retomar para voltar.
  2. Markdown: edite o rascunho. A prévia acompanha as alterações. Compare com a versão carregada ou baixe o arquivo.
  3. PDF: selecione um arquivo do computador ou uma fonte local cadastrada. Navegue, amplie e selecione texto quando o PDF tiver camada textual.
  4. Edição PDF: experimente a diagramação de impressão do rascunho. Esta paginação pertence à edição preparada, não à fonte histórica.
  5. Gravação: “Revisar e salvar” encaminha o rascunho à prévia editorial existente. A confirmação de gravação acontece lá.

A bancada começa sem projeto ativo. Escolha explicitamente um projeto para trabalhar em suas versões privadas; incorporar ao acervo exige outra confirmação. Rascunhos e notas ficam nesta sessão; baixe uma cópia antes de encerrar o navegador. A interface oficial continua disponível nos links superiores.
