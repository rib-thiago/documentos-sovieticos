# Workspace editorial IDE — protótipo

Abra **http://127.0.0.1:8000/prototipo/ide/** após iniciar/reiniciar `python3 -m backend`.

Diagnóstico, arquitetura, limites e roteiro: [WORKSPACE-IDE-DIAGNOSTICO.md](../../docs/projeto/WORKSPACE-IDE-DIAGNOSTICO.md).

A interface oficial não foi substituída. Rascunhos do protótipo são de sessão; os formulários editoriais incorporados fazem gravações locais reais somente pelos seus próprios fluxos de confirmação.
